📋 PREREQUIS
─────────────────────────────────────────────────────────────────
  ✓ Python 3.11+
  ✓ MySQL 8.0+ ou MariaDB 10.6+
  ✓ Node.js 18+


🚀 INSTALLATION AUTOMATIQUE (RECOMMANDE)
─────────────────────────────────────────────────────────────────

1. Ouvrir PowerShell dans le dossier backend/

2. Executer :
   .\configure_mysql.bat

3. Suivre les instructions et entrer le mot de passe root MySQL

   ⚡ C'est tout ! Le script fait tout automatiquement.


✅ VERIFICATION
─────────────────────────────────────────────────────────────────

Tester la connexion MySQL :
   venv\Scripts\activate
   python test_mysql_connection.py

Resultat attendu : "✅ Connexion réussie !"

🐛 DEPANNAGE RAPIDE
─────────────────────────────────────────────────────────────────

❌ "Access denied for user"
   → Verifier le mot de passe dans .env
   → Recreer l'utilisateur MySQL (voir docs)

❌ "Can't connect to MySQL server"
   → Verifier que MySQL est lance
   → Services Windows → MySQL → Demarrer

❌ "Unknown database"
   → Creer la base : mysql -u root -p < setup_mysql.sql

❌ "No module named 'pymysql'"
   → Installer : pip install pymysql cryptography
